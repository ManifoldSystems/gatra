# Gatra-10M assistant-only SFT pilot v1

Completed two epochs / 814 SFT-local attempted updates from pretraining step
88,138. Training: 4,000 Alpaca, 1,511 TyDi QA, 1,000 Cendol examples (6,511 total).
Validation: 200 Alpaca, 157 TyDi QA, 200 Cendol (557 total). FP16 batch 16, context
512 bytes, fresh AdamW, peak LR 1e-5. No overflow-skipped updates.

| Assistant-only validation | Before | Epoch 1 | Epoch 2 |
| --- | ---: | ---: | ---: |
| All sources, target-byte-weighted | 0.7810 | 0.5933 | 0.5851 |
| Alpaca | 0.7860 | 0.7558 | 0.7507 |
| Cendol | 0.7861 | 0.4604 | 0.4517 |
| TyDi QA | 0.7391 | 0.3591 | 0.3387 |

General-text fixed-window validation loss rose from 0.971670 before SFT to
0.977776 afterwards (~0.63%). This uses the same FP32 256-byte windows as the
previous checkpoint comparison. It is a small measured regression on that
sample, not a statement about every domain.

## Generation findings

The original 12-prompt/two-seed suite is saved in `results.json`. Four additional
template-matched probes use `User: ...\n\nAssistant: `, seed 1337, temperature
0.4, top-k 40, top-p 0.9 and 96 generated bytes for both the base and SFT models;
see `template-probes.json`.

- Tokyo and 2+3 still fail. Named-cat retrieval still repeats Miko and misses Milo.
- For the exact-copy chat probe, the SFT response begins with the requested
  sentence but continues with invented Assistant turns. This is partial copying,
  not successful exact-output instruction following.
- Paraphrase boilerplate appears even for direct questions: the Japanese-capital
  question becomes “Ok, berikut hasilnya: Apa itu kota Jepang?”.
- Text continuation remains semantically unstable and can introduce chat markers.

Conclusion: the objective is learnable, but aggregate held-out answer loss hides
undesirable task/style transfer. Do not promote this checkpoint as a generally
better chatbot. Retain the pretraining checkpoint as the control. Before another
run, remove or sharply reduce paraphrase boilerplate, improve semantic correctness
of short QA, and define an answer-ending convention with generation stopping.
Compare task success and general-text loss, not only teacher-forced answer loss.
